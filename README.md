# DmFirst Official - Entertainment & Rewards Platform

Complete 1:1 identical copy of [DmFirst (dmfirst0.com)](https://www.dmfirst0.com/) with all original images, logos, banners, game graphics, audio, UI components, and Supabase integration.

## How to Run

1. Open terminal in the `dmfirst` project folder:
   ```bash
   cd dmfirst
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Open your browser at:
   ```
   http://localhost:5173
   ```

## Production Build & Preview

To create a production build and preview it:
```bash
npm run build
npm run preview
```

## Features Included
- **Exact UI & Styling:** 100% matched color scheme, typography, layouts, animations, and responsive mobile-first views.
- **Complete Asset Pack (1,400+ assets):** High-definition logos, game thumbnails (Lottery, Slots, Sports, Flash, Chess, Fish, Video), VIP badges, banners, icons, and audio.
- **Supabase Integration:** Connected to your project `dmfirst` (`pylgiqhcnilxvspyascz`) with client helper in `src/lib/supabaseClient.ts`.
